# テニスプラザ尼崎 採用LP A/Bビジュアル設計レビュー

作成日：2026-05-24

対象：

- `tennis_plaza_recruit_lp_visual_design_variant_A.md`
- `tennis_plaza_recruit_lp_visual_design_variant_B.md`
- `tennis_plaza_recruit_lp_visual_design_AB_compare.md`

## 1. 総評

A/Bの方向性はどちらも成立している。

特に良い点は、単なる見た目の違いではなく、以下のように「誰に何を伝えるか」が分かれていること。

```text
A：若年層に、ここで働くことの熱量と今っぽさを伝える
B：山下社長・経験者・保護者に、テニプラの品と思想を伝える
```

ただし、山下社長への初回提示としては、A/Bを同格でフルに見せるより、以下が安全。

```text
本命：B案 Court Editorial
補助：A案 Rally Burst の Hero / Career / CTA だけを若手採用向け演出サンプルとして見せる
最終推奨：Bをベースに、HeroとCareerにAのエネルギーを少し入れた Hybrid C
```

理由は、今回の本質が「若者向けに派手な採用LPを作ること」ではなく、

```text
山下社長の勝ちパターンを、採用・育成・入会導線・西宮展開まで再現可能なブランドにすること
```

だから。

## 2. A案 Rally Burst のレビュー

### 良い点

- 若年層に対する第一印象は強い
- `テニス経験 → キャリア` の変換が視覚的に伝わりやすい
- Hero / Career / Final CTA のデモ映えが強い
- スカウト文、SNS広告、採用キャンペーンへの転用に向く
- 「既存HPとは明らかに違う」インパクトが出る

### 懸念点

#### 1. 山下社長には「派手すぎる」と見えるリスクが高い

Yellow 18% は、地域密着テニススクールの採用・育成提案としては強い。
社長が「若手向けにはいいけど、うちの空気感とは違う」と感じる可能性がある。

#### 2. Nike SB / ストリート文脈がズレる可能性

若手には刺さるが、山下社長・保護者・経験者には、ストリート寄りの参照がやや遠い。
テニスプラザ尼崎は「尖ったスポーツブランド」より「地域で信頼されるスクール」の印象も必要。

#### 3. 横スクロールとScrollStackはデモでは映えるが、実装/保守リスクがある

特にSection 7の横スクロールは、スマホで破綻しやすい。
採用LPはスマホ閲覧比率が高い前提なので、PC専用の見せ場にするならよいが、主構造にしすぎるのは危険。

### A案の修正推奨

- Yellow使用面積は本番想定では `18% → 8〜12%` に落とす
- Aを全面採用するより、Hero / Career / CTA の演出パーツとして使う
- 「Nike SB」より「On Running / テニスブランド / スポーツクラブの採用キャンペーン」寄りに言語化する
- Section 7はPCでは横スクロール、SPでは縦タイムラインに必ず切り替える

## 3. B案 Court Editorial のレビュー

### 良い点

- 山下社長に「ちゃんと考えてきた」と感じさせやすい
- 山下コーチ哲学、近江さんメッセージ、Future Roadmapとの相性が良い
- 採用LPだけでなく、HP本体・西宮テニスクラブLP・保護者向けLPへ転用しやすい
- 長文を読ませる構造なので、今回のような「課題の解像度を上げる提案」に向いている
- 20代だけでなく、30代経験者・接客営業経験者・保護者にも耐える

### 懸念点

#### 1. 若手採用LPとしては静かすぎる可能性

B案単体だと「品はあるが、働きたい熱量」はAより弱い。
テニス経験あり・指導未経験の20代には、やや大人っぽすぎる可能性がある。

#### 2. B&W写真が強すぎると、現場の明るさが消える

採用LPでは「人が良さそう」「楽しそう」「現場に行ってみたい」が重要。
B&W中心にしすぎると、上質だが冷たく見える可能性がある。

#### 3. Webフォント5書体は現実的に重い

特に `Noto Serif JP` は日本語フォントとして重くなりやすい。
`Total < 220KB` は理想としては良いが、日本語サブセット運用を相当丁寧にしないと厳しい。

### B案の修正推奨

- Bをベースにしつつ、HeroとCareerにはAの動きを20〜30%だけ入れる
- B&W写真は全面ではなく、`B&W 70% + 一部カラー` または `Warm documentary tone` にする
- フォントは初期実装では3系統に絞る
  - Noto Sans JP
  - Noto Serif JP
  - Inter
- Fraunces / JetBrains Mono は、必要なら後から限定導入する
- 章扉は3つ全部ではなく、初期は `Why Now` と `Future Roadmap` の2つに絞ってもよい

## 4. A/B比較ドキュメントへのレビュー

### 良い点

- A/Bの差分が明確
- ペルソナ別推奨が分かりやすい
- デモ台本があるので、当日の話し方までイメージできる
- Hybrid Cを隠し玉として持つ設計は良い

### 修正した方がよい点

#### 1. 「2案見せて社長に選ばせる」は少し危険

山下社長はデザインディレクターではない。
2案を同格で見せると、色や好みの話に寄り、採用・育成・事業成長の本質からズレる可能性がある。

推奨は以下。

```text
1. まずB案を本命として見せる
2. 「若手採用にもっと振るなら、こういうAの演出もあります」とHeroだけ見せる
3. 反応を見て、Hybrid Cを推奨として提示する
```

#### 2. 台本はA→Bではなく、B→A補足の方がよい

現在の台本はAを先に見せる。
これはデモ映えするが、社長の第一印象が「派手」になるリスクがある。

推奨順：

```text
Step 1：前置き
Step 2：B案のWhy Now / 山下哲学 / Future Roadmapを見せる
Step 3：A案のHero / Careerだけ見せる
Step 4：Hybrid Cを推奨として提示
Step 5：質問とヒアリングへ
```

#### 3. Hybrid Cは「隠し玉」ではなく、社内推奨にしてよい

比較ドキュメントでは「B → Hybrid C」とあるが、実際の完成形としては Hybrid C が最も強い。

理由：

- 山下社長にはBの信頼感が必要
- 求職者にはAの熱量が必要
- 近江さんには現場の温度感が必要
- 西宮展開にはBの転用性が必要

つまり、最終的には以下が自然。

```text
ベース：B
Hero：Aを30%混ぜる
Career：AのScrollStackを簡略版で混ぜる
CTA：AのYellow energyを少量混ぜる
その他：B
```

## 5. 最終推奨

### 提案方針

```text
本命は B案 Court Editorial。
ただし、採用LPとして若手に届く熱量が必要なため、
Hero / Career / CTA だけ A案 Rally Burst のエネルギーを部分採用する。
```

呼び名：

```text
Hybrid C：Court Editorial with Rally Moments
```

### 採用する要素

| 領域 | 採用案 | 理由 |
---|---|---|
| 全体トーン | B | 山下社長・保護者・西宮展開に耐える |
| Hero | B構造 + Aのラリー軌道/Yellow少量 | 第一印象に動きを出す |
| Why Now | B | 経営課題への理解が伝わる |
| 共感 | B | 読ませる構造が向く |
| 理想人材 | B | 言語化の説得力が出る |
| 山下哲学 | B | 本人の思想を立てられる |
| 体験→入会 | Bベース + Aのラリー比喩 | 横スクロールではなく縦タイムライン推奨 |
| 育成体制 | B | 研修/評価制度に転用しやすい |
| Career | A簡略版 | 求職者の将来性を体感させる |
| AIロープレ | B | やりすぎると主役がズレる |
| 募集要項/FAQ | B | 信頼感・読みやすさ優先 |
| Final CTA | B + Yellow CTA | 最後だけ少し熱量を戻す |
| Future Roadmap | B | HP/西宮LPへの広がりを見せる |

## 6. 実装時の注意

### 6-1. フォントを増やしすぎない

初期実装は以下に絞る。

```text
Noto Sans JP
Noto Serif JP
Inter
```

A用に `Inter Tight` を入れる場合も、Heroだけに限定する。
`Fraunces` と `JetBrains Mono` は、初回では必須ではない。

### 6-2. Yellowは少量でよい

本番推奨：

```text
Yellow使用面積：5〜8%
```

CTA、Heroラリー軌道、Career Step 3、Final CTAに限定する。

### 6-3. 横スクロールは避ける

Section 7「体験から入会まで」はLPの重要セクション。
ここで操作性にクセが出ると、内容が伝わる前に離脱する。

推奨：

```text
PC：縦タイムライン + 軽いラリー軌道
SP：通常の縦カード
```

### 6-4. B&W写真は使いすぎない

山下哲学やFuture Roadmapでは良い。
ただしHeroや近江さんメッセージは、現場の明るさが必要。

推奨：

```text
Hero：カラー寄りの実写
山下哲学：B&W寄りでも可
近江さん：カラー推奨
Future：B&W/Editorial可
```

### 6-5. 19セクションは長いので、公開版とMTG版を分ける

MTGデモでは19セクションで良い。
公開版では、Future Roadmapなど一部は非公開/別ページ化してもよい。

```text
MTG版：19セクション
公開版：16〜18セクション程度
社長向け補足：Future Roadmapを残す
```

## 7. 提案時の言い方

社長には「AとBどちらが好きですか？」ではなく、こう言う方がよい。

```text
採用LPの見せ方には、大きく2方向あると思っています。

1つは、若い人に一瞬で届くスポーツブランド寄りの見せ方。
もう1つは、山下さんの指導思想やテニプラの品を、採用ブランドとして立てる見せ方です。

今回の本命は、後者のエディトリアル寄りです。
ただ、採用ページとしては若い人に届く熱量も必要なので、
Heroやキャリアパスだけは少しスポーツブランド寄りの動きを入れるのが良いと考えています。
```

この言い方なら、社長が「選ばされる」感じではなく、
こちらがプロとして方向性を持って提案している印象になる。

## 8. 結論

A/B設計は方向性として問題ない。

ただし、最終提案としては以下を推奨する。

```text
Pure A：採用キャンペーンとしては強いが、山下社長・保護者・西宮展開にはやや派手。
Pure B：山下社長には刺さるが、若手採用の熱量がやや弱い。
Hybrid C：Bを土台に、Hero / Career / CTAだけAの熱量を足す。最も今回の目的に合う。
```

したがって、実装方針は以下。

```text
Court Editorial with Rally Moments
```

これを最終デザイン方針にするのが、現時点で一番安全かつ強い。
