# テニスプラザ尼崎 採用LP コピー/導線レビュー

作成日：2026-05-24

## 1. レビューの前提

このLPのゴールは「その場で応募させる」よりも、まずは心理的ハードルの低い見学・カジュアル面談へ進ませること。

そのため、コピー設計では以下を優先した。

- テニス経験者に「自分にも関係がある仕事」と感じてもらう
- コーチ未経験者に「いきなり任される不安」を持たせない
- コーチ経験者に「教えるだけで終わらない広がり」を見せる
- 接客・営業経験者に「自分の経験が活きる」と伝える
- 「営業」という言葉の圧を下げ、「入会案内」「不安を聞く」「合う通い方を提案する」に翻訳する
- 最終CTAまで「応募するかは見てから決めてよい」という逃げ道を残す

## 2. 想定ペルソナ別レビュー

### Persona A：テニス経験あり・指導未経験の20代〜30代

不安：

- 人に教えた経験がない
- コーチ職に将来性があるのか分からない
- 好きなことを仕事にしてよいのか迷う

刺さるメッセージ：

- コーチ未経験OK
- 研修あり
- いきなり一人で任せない
- テニス経験を、人の一歩を支える力へ

改善した点：

- `未経験OK` を `コーチ未経験OK` に変更
- Hero本文を「あなたのテニス経験を、誰かが一歩踏み出すきっかけに変えていきませんか」に変更
- FAQで「いきなり一人で任せるのではなく」を追加

### Persona B：コーチ経験者・スクール経験者

不安：

- またレッスンだけの仕事になるのではないか
- 裁量や運営側への広がりがあるか
- 自分の経験が評価されるか

刺さるメッセージ：

- レッスンだけでなく、体験対応・保護者対応・スクール運営にも関われる
- 運営・スクール成長担当へ広がる
- コーチ経験を、チームや事業を育てる力へ広げる

改善した点：

- キャリアパス最終段階に「チームや事業を育てる力」を追加
- 価値セクションで「人と向き合う経験が、将来につながる力になる」と補強

### Persona C：接客・営業経験者 × テニス経験者

不安：

- コーチ経験がない
- テニスの指導職として見てもらえるか
- 営業色が強すぎると抵抗がある

刺さるメッセージ：

- 入会案内は無理に売り込む仕事ではない
- 不安を聞き、合う通い方を一緒に考える仕事
- 接客や営業経験も活かせる役割

改善した点：

- Heroの `営業` を `入会案内` に変更
- 共感カードで「売り込む仕事は苦手かもしれない」に先回り
- キャリアStep 3に「接客や営業経験も活かせる役割」を追加

### Persona D：アルバイト・副業・学生に近い候補者

不安：

- 正社員前提だと重く感じる
- いきなり応募は怖い
- 自分の勤務条件が合うか分からない

刺さるメッセージ：

- 見学からOK
- アルバイトから始めることも相談可能
- 応募するかは見てから決めてよい

改善した点：

- Heroバッジに `見学からOK` を追加
- 選考フロー冒頭で「応募するかは決めきっていなくて大丈夫」と明記

## 4. 現状の改善点サマリー

今回の改善で、離脱しやすいポイントはかなり減った。

特に改善したのは以下。

- `営業` の直接表現を減らし、求職者が抵抗を持ちにくい `入会案内` `不安を聞く` `合う通い方を提案する` に変換
- `未経験OK` の誤解を避けるため `コーチ未経験OK` に変更
- 見学導線を「応募する前の確認」として明確化
- コーチ経験者に向けて、運営・チーム・事業成長への広がりを補強
- 接客/営業経験者に向けて、体験・入会フォローで経験が活きることを明記
