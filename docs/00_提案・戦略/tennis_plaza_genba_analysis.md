# テニスプラザ尼崎 現状分析サマリー
作成: アリガトサン戦略チーム / 2026-06-08 / 6-15 MTG（山下社長・近江様）用

---

## 1. 全体サマリー（3行）

- **強み**: 会員数・売上が好調な既存事業基盤に加え、SNS上に「技術リール×実名コーチ」という再現性のあるコンテンツ資産（最大18.5万再生のコラボ実績）を既に保有している。集客力そのものは弱くない。
- **弱み**: その資産が「採用」「ブランド」「計測」に接続されておらず、Instagramは統一感を欠き、HPは採用導線・計測設計が未整備、X・LINEは死蔵/未導入。**蛇口（媒体・露出）はあるのにバケツ（受け皿）に穴がある状態**（永吉観点）。
- **今つくべき一手の仮説**: HPの作り替えではなく、**「テニプラで働く魅力＝採用ブランド」を上流で定義し、既存の強い資産（技術リール・コーチ実名・好調な事業）を採用導線（LP/求人票/スカウト/LINE窓口）に流し込む**こと。最速で「社員1+バイト2」を採り、近江様を現場から手離れさせるのが直近ゴール。

## 2. Web/HP現状診断（tennisplaza.jp）

吉川観点フレーム（今何が悪い／放置するとどうなる／作り替え後の相乗効果）で整理する。実数はGA4/Search Console認証取得済みのため後日差込。現時点は想定課題ベース。

### 2-1. 今、何が悪いか（想定課題）

| 領域 | 想定課題 |
|---|---|
| 集客導線 | 体験予約・問い合わせへのCTAが弱い/分散している可能性。「体験予約」が1クリックで完結する動線になっているか要確認。スマホでの予約完了率が落ちやすい構造の可能性。 |
| 採用導線 | 採用ページがHP本体に統合されていない/薄い。採用LP（/recruit）は実装済みだが、**HP本体からの送客動線**と**SNS→LP**の接続が未設計。「テニプラで働く魅力」がHP上で言語化されていない（中村観点：テニスコーチのキャリアが見えない）。 |
| SEO土台 | ブログ/コラム資産が体系化されていない可能性。「尼崎 テニススクール」「西宮 テニススクール」等の地域×サービス検索での上位獲得構造（タイトル設計/内部リンク/コーチ別ページ）が未整備の懸念。リールという強コンテンツがHPのSEO資産に転用されていない。 |
| 計測 | GA4/Search Console認証はアリガトサン側で取得済みだが、**CV（体験予約・問い合わせ）がイベントとして正しく計測されているか未確認**。計測されていなければ「どの施策が効いたか」を一切判断できない。 |

### 2-2. 放置するとどうなるか

- 採用は媒体（doda/リクルート）頼みになり**応募単価が高止まり**、かつ媒体経由でも「テニプラの魅力」が伝わらず歩留まりが悪い（バケツの穴）。
- 西宮再建フェーズで集客を仕掛ける際、**地域SEOの土台がないままリスティング広告に課金し続ける**ことになり、競合（ノア/コナミ等の体験0円訴求）に価格で消耗する。
- 計測未整備のまま施策を打つと、**費用対効果を数字で社内承認（上位オーナー＝承認Gate）に説明できない**。

### 2-3. 作り替え（上流再設計）後の相乗効果

- 採用ブランド→求人票/LP→SNS→LINE窓口が一本の動線になり、**SNSの強い再生数が応募という成果に初めて接続**される。
- 地域SEO土台×リールコンテンツの転用で、**広告費に依存しない自然流入の体験予約**が西宮フェーズで効く。
- CV計測が入ることで、火曜KPI設計（中田）が**実数ベースで回り、上位承認も数字で通せる**。

### 2-4. MTG後にGA4/サチコで見るべき指標（実数差込予定）

- セッション数 / ユーザー数（月次推移、デバイス別＝スマホ比率）
- 流入チャネル内訳（Organic Search / Direct / Social / Referral / Paid）
- Search Console 検索クエリ（「尼崎 テニス」等の地域KW順位・表示回数・CTR）
- ランディングページ別セッション（どのページが入口か）
- CV数とCV率（体験予約完了 / 問い合わせ送信 / 電話タップ）— **イベント設定の有無をまず確認**
- 採用LP（/recruit, /recruit/persona, /recruit/roadmap）の到達数・滞在・離脱

## 3. SNS現状診断 — 死蔵資産と伸びてる資産の切り分け

### 3-1. 資産の仕分け

| 媒体 | 状態 | 判定 |
|---|---|---|
| Instagram技術リール（中本悠水コラボ18.5万再生、コーチ別技術動画 各2,000-2,600再生で安定） | 伸びている・再現性あり | **伸びてる資産（主戦力）** |
| Instagramフィード（告知チラシ/商品/店内が雑多、フォロワー893/フォロー14） | ブランド感欠如・統一性なし | **要・全面作り直し（資産化前）** |
| X @tennipla（フォロワー78、2024年1月以降放置） | 実質停止・個人雑記運用 | **死蔵資産（当面凍結 or 整理）** |
| 公式LINE | 未導入 | **新規作成＝応募/問い合わせ窓口（最優先で着手）** |

### 3-2. 勝ち筋の言語化

**「技術リール × 実名コーチ × ブランド統一」**がテニプラのSNS勝ち筋。

- リールで回っているのは「SWING SPEED serve STEP1-3」等の**技術コンテンツ×実名コーチ**。これは①視聴者に価値があり②コーチが主役＝**採用ブランド（働く人の魅力）の証明**そのものになる。
- 採用ペルソナ（三浦涼太：好きだったテニスをもう一度/対人力を活かす）に対し、**「このコーチたちの一員になれる」**という訴求がリール資産で既に半分できている。
- フィードはブランドトーン（配色/テンプレ/語り口）を統一し、リールの受け皿として整える。視聴者→プロフィール→LINE/採用LPの導線を作る。
- 顔出しOK・LINE新設の確認が取れているため、**運用代行をアリガトサンがプラン分けして提供**（近江様の「ネタ仕入れの手間」懸念を解消）する前提が成立している。

## 4. 既存業者（株式会社アレッジ / MEO月5,000円）の位置づけ

**否定せず、レイヤーが違うものとして整理する。**

- MEO（Googleマップ最適化）は**ローカル来店集客の下流施策**として並走可能。月5,000円は金額として大きくないため、即解約を提案する論点ではない。
- ただし**レポート/費用対効果の実態が不明**なため、MTGで「現状どんなレポートが来ているか/口コミ件数・マップ経由問い合わせの推移」を確認する（数字が出せないなら見直し検討）。
- 今回アリガトサンが担うのは**採用ブランドとブランド統一・採用導線・計測という上流設計**であり、MEOとは競合しない。「MEOは並走、採用とブランドの上流は別物」と整理して提示する。

## 5. 競合状況

### 5-1. 採用競合（人材を奪い合う相手）

| 競合 | 脅威 | アリガトサンが上流で勝てる点 |
|---|---|---|
| doda / リクルート / Indeed | 圧倒的な母集団（蛇口の太さ）。テニプラも商談中。 | 媒体は「蛇口」。**バケツ（採用ブランド/求人票/LP/面接導線）を磨けば同じ蛇口でも歩留まりが上がる**。媒体に出す原稿・スカウト文・面接設計をテンプレ化（中村案：理想人物像/条件/魅力PRをAIで半自動スカウト）して差別化。 |
| 人材紹介エージェント | 即戦力を持ってくる | **法務注意**：紹介成功報酬は職業紹介事業に触れうる。アリガトサンは「採用マーケ支援/採用広報/スカウト文・求人票・LP設計」に寄せる。AIスカウトは「半自動（最終送信・判断は人）」と表現。 |

**上流の勝ち筋**：競合は「蛇口」を売る。アリガトサンは「テニプラにしかない魅力＝採用ブランド」を定義し、ペルソナ（三浦涼太）に刺さる言葉（「好きだったテニスにもう一度」「未経験でも補助から」）で**応募の質と歩留まりを上げる**。これは媒体には作れない。

### 5-2. 西宮集客競合（西宮再建フェーズ）

| 競合 | 訴求 |
|---|---|
| ノア西宮 / ITCテニスヒル仁川 / コナミ西宮 | 体験0円・駅近・インドア・ナイター（=利便性と価格訴求） |

**上流の勝ち筋**：価格・設備の正面勝負は消耗戦になりやすい。テニプラの**実名コーチ×技術リールという「人とコンテンツ」の資産**で「このコーチに習いたい」という指名需要を作り、体験予約LP＋地域SEO＋（必要なら）バス施策/QRで送客する。広告だけに頼らない流入構造で差別化。
