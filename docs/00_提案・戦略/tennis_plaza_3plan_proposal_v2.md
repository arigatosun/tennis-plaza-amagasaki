## 1. 全体ストーリー ─ なぜ今、これをやるのか

### 結論を一言で

> **テニスプラザ尼崎さんは「お客さんはちゃんと来ているのに、レジが無い店」です。**

集客が弱いのではありません。むしろ土壌は良い。問題は「**何件取れているか誰も数えられない**」「**いちばん強い武器（Instagram）がホームページに繋がっていない**」こと。だから本提案は「もっとお客を呼ぶ」話ではなく、**「今来ているお客を取りこぼさず、数えられる状態にする」**ことから始めます。

### 私たちが実際の数字（GA4）で見つけた問題

| | 何が起きているか | ひとことで言うと |
|---|---|---|
| ① | 予約・問い合わせ・電話・入会の**計測がゼロ** | レジが無い。何件取れているか不明 |
| ② | Instagram（フォロワー893・リール最大18.5万再生）→ HPは**月25訪問（全体の1.5%）** | 最強の武器がHPに繋がっていない |
| ③ | 有料SNS広告が動いているのに**滞在22秒**で離脱 | 広告費の無駄打ち（出稿元・費用も不明） |
| ④ | Search Console未連携 | どんな検索語で来ているかが見えない |
| ⑤ | リンク切れ（404）が**月275回** | 来た人を取りこぼしている |
| ⑥ | モバイル68%・月約1,650訪問・検索のエンゲージ率76% | スマホ中心。**土壌そのものは良い** |

> つまり「**蛇口（SNS・検索）は強い。バケツ（HP）に穴があり、レジ（計測）が無い**」。

### だから、何をするか

採用ブランドの設計を起点に、最速で**社員1名＋アルバイト2名**を採用し、近江さん（まやのさん）を現場実務から手離れさせる。そのうえで集客を取りこぼさない土台を整え、ゆくゆくは**西宮テニスクラブの再建**まで一緒に走る。この順番を、3つの選択肢でご用意しました。

### 3つの選択肢（このあと各論）

- **プランA：採用の入口だけ最速で立てる**（採用LP単体）
- **プランB：入口＋HPの穴を塞ぐ＝レジを置く**（本提案の推奨ライン）
- **プランC：穴を塞ぎ、武器を成果に変え続ける仕組みまで作り、月次で伴走**（本命・西宮までの長期伴走）

## 4. 推奨プランと、その理由／単発→伴走の道筋

### 推奨は「プランB」。ただしゴールは「プランC」。

初手のベストは**プランB**です。理由は3つ。

1. **承認が通りやすい**。「計測＝レジ設置」「致命傷の止血」は、誰が見ても“やらない理由がない”投資。上位オーナーへの説明が数字で完結します。
2. **採用と既存事業の両輪に同時に効く**。Aだと採用しか動かず、近江さん手離れ後に向かう“集客”の土台が未着手のまま。Bは受け皿（計測された集客）まで先に用意できます。
3. **Cはいきなりだと重い**。運用伴走の価値は「数字が見えてから」が一番伝わる。計測のないままCを契約しても、レビューする数字がありません。**まず計測（B）、次に運用（C）が正しい順番**です。

### 単発（B）→ 伴走（C）への自然な道筋

> **「Bでレジを置くと、初めて“出血量”が数字で見える。その数字が、Cを必要にします。」**

1. **B（単発）でレジを置く** → 「Instagram経由で月◯件取れていた／いなかった」「広告から何件入会したか」が初めて見える。問題が“感覚”から“数字”になる。
2. **見えた数字が次の問いを生む** → 「リール18.5万再生がCV◯件なら、型化したら何件？」「広告を止めて、その費用を運用に回したら？」。この問いはBの納品物（ダッシュボード）が自動的に提示する。
3. **問いに答え続ける体制＝月次伴走（C）へ** → Bの納品物が、そのままCのご提案資料になる。押し売りでなく、数字が次を求める構造。
4. **西宮へ** → Cで近江さんが手離れし集客が回り出した実績そのものが、上位オーナーへの「西宮も任せられる」という最大の証跡になる。

### 価値の根拠（金額の隣に置くもの）

- **人材紹介を使わない節約**：doda／リクルート等は成功報酬30〜35%＝社員1人で85〜123万円。社員1＋バイト2なら**約170〜250万円**。本提案は無料媒体＋スポキャリ（¥55,000）で同じ採用を狙う設計。**この浮いた採用コストの範囲内で、採用LPだけでなくHPの止血や運用の仕組みまで残る。**
- **消える費用か、残る資産か**：人材紹介は採るたびに毎回消える。私たちは採用の仕組みそのものを御社に残し、次の採用も自前で回せるようにする。
- **数字が見える**：B以上は計測ダッシュボード付き。承認した投資が効いているかを、毎月ご自身で確認できる。

### 上位オーナーの承認を通すために

> **山下社長には“関係性と熱量”で。上位オーナーには“計測された数字”で。**

そのまま上の方に見せられる1枚（GA4の①〜⑥＋人材紹介170〜250万円との比較）をご用意します。突くのは「**現状、何件取れているか答えられますか？**」。答えられない＝レジが無い、という投資判断以前の盲点です。
