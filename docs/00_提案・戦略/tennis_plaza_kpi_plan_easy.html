この資料の読み方

3つだけ覚えてください。
① 蛇口（じゃぐち）＝お客さん・応募者を呼び込む入口（SNSや検索）。テニスプラザ尼崎はここが強い。
② バケツ＝呼び込んだ人を受け止める場所（ホームページ＝HP、求人ページ、LINEなど）。ここに「穴」が空いている。
③ レジ＝お客さんが「申し込んだ・問い合わせた」を数える仕組み（＝計測）。今これが付いていないので、何件取れているか分からない。
読み方のルール
・各章のあたまに「💬 ひとことで言うと」があります。まずそこだけ読めば全体がつかめます。
・むずかしいカタカナ語には、その場で（カッコ書きの意味）を付けています。
・数字のうち、まだ確定していない「えいやで置いた推測値」には 【仮置き】 と書いています。MTGで本物の数字に差し替えます。

📖 用語ミニ辞典（このページに戻ってこればOK）

セッション（訪問）誰かがサイトに1回来た、の単位。「お店に1回入ってきた」と同じ感覚。同じ人が2回来れば2セッション。
チャネルお客さんが「どの入口から来たか」の種類。検索から／SNSから／直接URLから、など。お店でいう「正面入口・裏口・紹介」の違い。
Organic Search
（オーガニック検索＝自然検索）		Googleなどで検索して、広告ではなく普通の検索結果から来た人。「お金を払わずに検索で見つけてもらえた」入口。テニスプラザ尼崎の主力（76%）。
Organic Social
（SNS自然流入）		InstagramやXなどSNSの投稿を見て、広告ではなく自然に来てくれた人。「投稿を見て遊びに来た」入口。
Paid Social
（ペイドソーシャル＝SNS広告）		お金を払って出すSNSの広告から来た人。今これが動いているが、誰がお金を払って出しているか不明という謎の状態。
Direct（ダイレクト＝直接）URLを直接入力・ブックマーク・QRなどで、入口を経由せず来た人。「お店の名前を知っていて直接来た常連さん」に近い。
エンゲージメント率来た人が「ちゃんと中身を見てくれた割合」。高いほど「来た人が満足して読んでいる」。テニスプラザ尼崎は76%＝かなり良い。
コンバージョン（CV＝成果）サイトに来た人が「予約した・問い合わせた・電話した・入会した」など、こちらが欲しい行動をしてくれること。＝レジで会計が成立した瞬間。今これを数えていない。
Search Console
（サーチコンソール）		Googleが無料でくれる「どんな検索ワードで来たか」が分かる健康診断ツール。今これがサイトとつながっていない（未連携）。
utm（ユーティーエム）リンクの末尾に付ける「目印タグ」。これを付けると「このInstagram投稿から何人来た」が分かる。＝荷物に貼る追跡シール。
リテンション
（＝定着・継続）		一度入った会員が「やめずに続けてくれること」。退会の反対。採用でも「採った人が辞めずに残る」の意味で使う。
404（よんまるよん）エラー「そのページは見つかりません」という行き止まり画面。月275回も発生＝来た人が壁にぶつかって帰っている状態。

① 現状ベースライン（今の実数）

💬 ひとことで言うと
「人はちゃんと来ているし、来た人の満足度も高い。でも“何件申し込まれたか”を数える仕組みがゼロで、せっかくの入口（SNS）がHPにつながっていない」。蛇口は強い、でもバケツに穴。
項目実数（確定）やさしい意味
月間の訪問約1,650セッション/月毎月1,650回サイトに人が来ている。少なくはない。
入口の内訳検索76% / 直接22% / SNS自然1.5%ほとんどが「検索」で見つけて来てくれている。SNSからの自然流入は月25訪問だけ＝伸びしろの宝庫。
SNS広告（Paid Social）12か月で292訪問・滞在22秒誰かがお金を払って広告を出しているが、出稿主も費用も不明。滞在22秒は短い＝来てもすぐ帰っている。
スマホ比率68%3人に2人はスマホで見ている。スマホで見やすいことが最優先。
来た人の質（エンゲージメント率）検索流入76%来た人の質は高い。中身はちゃんと読まれている。
成果（CV）の計測ゼロ・未設定何件予約・問い合わせ・入会が出たか、まったく数えていない。＝レジが付いていない。
Search Console未連携「どんなワードで来たか」が見えない。健康診断を受けていない状態。
404エラー月275回月に275回も「ページが見つかりません」の行き止まりが発生。来た人を取りこぼしている。
Instagramフォロワー893・リール最大18.5万再生大きな資産。だが見た人がHPに来ていない（つながっていない）。
X（@tennipla）放置使われていない。
公式LINE未開設受け皿（バケツ）がそもそも無い。
MEO（アレッジ社）月5,000円地図検索対策に払っているが、費用対効果は不明。
結論：「集客力が無い」のではなく「成果を数える仕組みと、入口から受け皿への導線が無い」。直すべきは集客より先に計測と受け皿。

② North Star（最終ゴール）

💬 ひとことで言うと
「90日で、社員1人とバイト2人を採用しきる。そうすれば近江さん（現場をひとりで回しているオーナー）が決まった現場シフトから外れられる。そこが第一目標」。
North Star（北極星＝迷ったらここに立ち返る唯一のゴール）
90日で「社員1＋バイト2」を採用完了し、近江さんが現場の固定シフトから外れる。

なぜこの順番か（採用 → 集客 → 西宮）

順番やること理由（やさしく）
1番目採用（社員1＋バイト2）まず人を増やさないと、近江さんが現場に縛られたまま。人が増えて初めて手が空く。
2番目集客（生徒を増やす）近江さんの手が空けば、集客に頭を使える。先に集客しても回す人がいない。
3番目西宮テニスクラブ再建尼崎が安定して初めて、次の大きな再建に着手できる。
大事：この順番は「同時にやれば速い」ものではなく順次必須（前が終わらないと次が始まらない）。だから採用を最速で片付ける。

③【Phase 0】計測基盤＝「レジを付ける」

💬 ひとことで言うと
「いちばん最初にやるのは、広告でも求人でもなく“数える仕組み”を付けること。今はお店にレジが無くて、何個売れたか分からないまま営業している状態。だからまずレジ（計測）を付ける」。これが全ての前提。
今の問題：成果（CV）の計測がゼロ。Search Console（検索ワードの健康診断）も未連携。これでは「広告にいくら使えば何件取れる」が一生分からない＝お金の使い方を決められない。

Phase 0でやること（受け皿に穴を空けないための土台）

やることやさしい意味（たとえ）
① CVキーイベント6種の設定
（体験予約完了／問い合わせ送信／電話タップ tel:／入会フォーム到達／LINE登録クリック／資料ダウンロード）		「どの行動を“成果”として数えるか」をレジに登録する。6種類のボタンを押された回数を数えられるようにする。
② Search Console 連携Googleの無料健康診断ツールをサイトにつなぐ。「どんなワードで来ているか」が見えるようになる。
③ utm（追跡シール）の付与Instagramなどのリンクに目印を付け、「どの投稿から何人来たか」を分かるようにする。
④ 採用管理シート応募者を一覧で管理する名簿。誰がどこまで進んだか（応募→面談→内定）を1枚で見る。
⑤ KPIダッシュボード大事な数字（応募数・成果数など）を1画面でいつでも見られる計器パネル。
⑥ 404 → 301 の修正月275回の行き止まり（404）を、正しいページへ自動転送（301）して取りこぼしを止める。＝壁に扉を付ける。
順序の鉄則（永吉フレーム：蛇口とバケツ）
媒体・広告＝蛇口（水を出す）。ブランド・LP（応募の受け皿ページ）・求人票・面談導線＝バケツ。
バケツの穴を先に塞ぐ。穴の空いたバケツに水（広告費）を注いでも全部こぼれる。だから順番は必ず：
計測（レジ）→ ブランド確定 → 受け皿（求人票・LP・LINE）→ 流入（蛇口を開ける）。

④ 採用の逆算（応募は何件必要か）

💬 ひとことで言うと
「3人採るには、面接や面談で人が減っていくぶんを見越して、最初に“応募50件”を集める必要がある。ゴールから逆算すると、入口に何人呼べばいいかが見える」。
注意：下の歩留まり（次の段階に進む割合）は 【仮置き】。実際の採用が進めば本物の数字に差し替えます。安全係数2.5＝「読みより厳しめに2.5倍多めに集める」安全マージン。
段階必要数（90日）次に進む割合【仮置き】やさしい意味
LP到達（求人ページに来る）650人―まず求人ページに650人来てもらう。
応募50件LP→応募 8%650人のうち約8%、50件が実際に応募。
カジュアル面談22件応募→面談 60%応募者の6割と気軽な面談を実施。
最終面接9件面談→最終 50%面談者の半分が最終面接へ。
内定5件最終→内定 70%最終面接者の7割に内定を出す。
承諾（採用決定）3人内定→承諾 80%内定の8割が承諾＝社員1＋バイト2が成立。
読み方
「3人ほしい」→ 内定5 → 最終9 → 面談22 → 応募50 → 求人ページに650人呼ぶ。
つまり最終ゴールは「求人ページに90日で650人」を集めること。次の章でその650人をどこから連れてくるかを決める。

⑤ どこから何人（チャネル配分）

💬 ひとことで言うと
「650人をどの入口から連れてくるか。いちばん伸びしろが大きいのはInstagram。今ほぼHPに送れていないが、ここを約10倍にできれば主力になる」。
入口（チャネル）配分求人ページ到達の目安やさしい意味
Instagram40%約260人/90日最大の武器。18.5万再生の資産あり。今は月25訪問しかHPに来ていない → 月260（約10倍）が伸び代。
採用媒体（doda等）30%約195人/90日応募者を集める専門サービス。お金で蛇口を太くする。競合ではなく上流の補完として使う。
HP・SEO（検索対策）20%約130人/90日もともと強い検索の流れに「求人ページ」を載せる。既存の強みを活かす。

キモ：Instagram（18.5万再生・フォロワー893）というすでにある資産を、HPの求人ページにつなぐだけで大きく伸びる。新しく何かを作るより「今ある蛇口を受け皿につなぐ」のが最短。

⑥ 90日の流れ（週ごとの大枠）

💬 ひとことで言うと
「最初の2週間でレジ（計測）と受け皿を作り、そのあとで初めて蛇口（広告・SNS）を開ける。土台ができる前に水を出さない」。
時期やることたとえ
第1〜2週Phase 0：計測6種・SC連携・utm・404修正・採用管理シート・ダッシュボードレジを付け、バケツの穴を塞ぐ。
第2〜3週採用ブランド確定（どんな職場として見せるか）看板を決める。
第3〜4週受け皿づくり：求人票・LP（応募ページ）・公式LINE開設バケツを用意する。
第4週〜流入開始：Instagram運用・媒体出稿・チラシ → 応募を集める蛇口を開ける。
第5〜10週応募対応・カジュアル面談・最終面接（数字を見ながら微調整）来た水をバケツで受ける。
第10〜13週内定・承諾 → 社員1＋バイト2 確定／近江さん手離れゴール到達。
原則：順序（計測→ブランド→受け皿→流入）は短縮しない。前が終わる前に次を始めると、結局やり直しになって遅くなる。

⑦ MTG（6/15）で埋める数字

💬 ひとことで言うと
「今“えやで置いている【仮置き】の数字”を、山下社長・近江さんとのMTGで本物に差し替える。ここが決まらないと予算も計画も確定できない」。
確認したい項目なぜ必要か（やさしく）
採用人数・期限本当に「社員1＋バイト2」「90日」でいいか。ゴールの再確認。
採用予算媒体・広告にいくら使えるか。蛇口の太さが決まる。
待遇条件（給与・勤務形態）求人票に書く中身。これが無いと応募ページが作れない。
SNS広告の出稿主・費用今動いている謎のPaid Social（SNS広告）は誰が・いくら払っているのか。無駄なら止める。
現スタッフ数今何人で回しているか。採用後の体制を設計する前提。
過去の採用経路これまでどこから人を採ったか。効く入口のヒント。
月謝単価1人の生徒がいくらか。集客の価値（売上インパクト）を計算する材料。
体験 → 入会率体験に来た人の何割が入会するか。集客効率の基準値。
退会率（リテンション）会員がどれだけ続く／辞めるか。集客と同じくらい大事。
チラシ配布先の可否どこに配れるか（近隣施設・提携先など）。チャネル10%の前提。
MTGの狙い
この10項目が埋まれば、【仮置き】が消えて「本物の数字に基づく計画」になる。MTGは“説明の場”ではなく“数字を確定させる場”。

選択肢内容犠牲になるもの
[A] 品質維持＋納期延長
（推奨）		やることは削らず、期限を後ろに伸ばす。スピード（少し遅くなる）。だが計画通りの質を守れる。

（非推奨）		急いで手早く回す。計測の精度や受け皿の作り込みが甘くなる。後でやり直しコスト。具体的な犠牲箇所はその都度明示する。

守る約束（法務・進め方のルール）

ルールやさしい意味
候補者紹介の成功報酬には踏み込まない「人を紹介してお金をもらう（職業紹介事業）」には手を出さない。法律の許可が要る領域なので避ける。
AIスカウトは半自動（最終送信は人）AIで効率化はするが、最後に送るボタンは必ず人が押す。誤送信・失礼を防ぐ。
媒体は競合ではなく上流補完doda等の採用媒体は敵ではなく、自社の入口を太くする味方として使う。
この資料のまとめ（30秒）

② だから順番は 計測 → ブランド → 受け皿 → 流入。バケツの穴を先に塞ぐ。
③ 90日で応募50件を集め、社員1＋バイト2を採用 → 近江さん手離れがゴール。
④ 【仮置き】の数字は6/15のMTGで本物に差し替える。
