## ③管理画面ログイン検証の結果（2026-06-23・本番ログイン試行）※GOを受けて実施 ※上記の通り後に人手ログインで解決

- ログイン画面は **SiteGuard WP Plugin** で保護:
  - ログインURL改名（`/login_93048` ＝ SiteGuard標準仕様）
  - **画像CAPTCHA（ひらがな）** 必須（`siteguard_captcha`）
  - **詳細エラーメッセージ無効化** ＝ パスワード誤りもCAPTCHA誤りも**同じ汎用文言**で返す（原因の切り分け不可）
  - ログインロック機能あり（※今回はフォーム到達可＝IPロックには未到達。ロックはIP単位・短時間で自然解除されるため、本番アカウント自体はロックされない）
- CAPTCHAは2枚を画素解析で高確度に判読（#1=「まつ」/#2=「いふ」）したが**いずれも失敗**。⇒ **CAPTCHAの誤読より、提供された資格情報（ID/PW）側が通っていない可能性が高い**。
  - 補足: PWは提供文字列をそのまま投入（特殊記号含め一致）。ただし `0`(ゼロ)/`O`、`6`等の**目視転記ゆれ**が原因の可能性は残る。
- ⇒ **3回で打ち止め**（IPロック回避のため）。次の切り分けは下記「ログイン不通の切り分け」。

## 含意（移行・計測の観点）
1. **サーバー現物はAuthCodeでは動かない**。AuthCodeはドメインのみ。WP本体・DB・メディアの移行は「③管理画面からのエクスポート / ベンダーへバックアップ依頼 / 作り直し」のいずれか。
2. **作業順序**: サイト現物の確保 → その後にドメイン移管・DNS切替。逆だと `tennisplaza.jp/login_93048`（管理画面）が一時的に到達不能になる。
3. **AuthCodeは今すぐ依頼しない**。現方針は Plan A 計測先行＝当面サーバー移行しない。移管はドメイン期限 **2026/09/30** の手前（遅くとも9月上旬）に、実移行を決めた直前で依頼するのが安全。
4. **Plan A（計測）の即効性**は、③アカウントの**権限レベル**に依存。Administrator かつ「ヘッダースクリプト追加 / プラグイン導入」が共用環境で許されていれば、サーバー移行なしで GA4・Clarity・CV計測を入れられる。権限が浅い場合はベンダーにタグ挿入を依頼する経路が必要。
