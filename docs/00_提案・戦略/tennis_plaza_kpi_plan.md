## 5. 集客ファネル（補助・順序は採用の後）

**依存関係（順次必須・短縮しない）**：
```
①採用充足（社員1+バイト2）→ ②現場が回る（近江手離れ）→ ③集客強化（体験↑）→ ④西宮再建
   [本計画の主戦場]                                          [次フェーズ]
```
集客で体験・入会が増えても、回すコーチがいなければ受け皿が破綻し近江の負荷が増す（目的と逆行）。よって採用先行が固定。

集客側KPI（採用充足後に起動・【仮置き】）：体験LP到達→体験申込5% / 体験申込→参加80% / 参加→入会40%。実数（現体験数・退会率＝【MTG確定】）で補正。

## 10. リスク・依存関係と「期限が厳しい場合の3択」

**依存関係（順次必須・並列化で短縮しない）**：
- 計測基盤(Phase0) → ブランド確定 → 受け皿(バケツ) → 流入(蛇口)
- 採用 → 集客 → 西宮

**主リスク**：①上位オーナー（金の亡者）の承認Gate ②近江の権限・工数の限界 ③CV未計測のまま流入を急ぐ近道。

**期限が90日確保できない場合の3択**：
| 選択肢 | 内容 | 犠牲 |
|---|---|---|
| **[A] 品質維持＋納期延長（推奨）** | バケツ整備を圧縮せず採用完了を90→120日 | 採用・近江手離れが後ろ倒し |
| [B] スコープ削減 | チャネルをIG＋媒体＋LINEの3本に集中（SEO/チラシ後送り） | 母集団がやや細る |
| [C] 近道許容（非推奨） | Phase0/バケツを簡易版で媒体先行出稿 | **成果計測欠落で改善不能・歩留まり低下・ブランド未確定で訴求ブレ** |

**推奨は[A]**。理由＝採用は「バケツの穴」が最も成果を毀損し、特に**今回は計測がゼロから**のため、Phase 0を飛ばす[C]は成果が一切見えないまま走ることになり最も危険。
