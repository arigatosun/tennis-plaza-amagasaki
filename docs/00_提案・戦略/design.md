# 提案書デッキ デザインシステム（PPTX生成の指針）

テニスプラザ尼崎 提案書（表紙＋GA4現状報告→3プラン提案）の通しPPTXを、見やすく図解中心で作るための統一仕様。`tennis_plaza_proposal_deck.pptx` 生成スクリプトはこの仕様に従う。

## 1. カラーパレット（ブランド）
| 役割 | HEX | 用途 |
|---|---|---|
| Primary（ディープグリーン） | `#0F3D2E` | 表紙背景・見出し・セクション扉 |
| Primary2 | `#264831` | サブ見出し・グラデ |
| Gold（アクセント） | `#E8A100` | 強調・推奨バッジ・キーワード下線 |
| Critical（赤） | `#C0392B` | 問題・致命傷・「ゼロ/無し」 |
| Good（緑） | `#1E8449` | 良い兆し・◎・解決 |
| Warn | `#C77C18` | △・注意 |
| Ink（本文） | `#1F2A26` | 本文テキスト |
| Mut（補足） | `#5D6B64` | 注釈・キャプション |
| Warm（背景） | `#F7F6F2` | スライド地・カード地 |
| Line | `#E3E1D8` | 罫線・枠 |
| White | `#FFFFFF` | カード・反転文字 |

## 2. タイポ
- 和文：游ゴシック / メイリオ（PPTXは "Meiryo" 指定で互換性確保）。
- スライドタイトル：28-32pt Bold（緑）。本文：14-18pt。キャプション：10-11pt（Mut）。数字の見せ場：40-60pt Bold。
- 1スライド1メッセージ。文字は詰め込まない（要点＋図解）。

## 3. スライド規格
- 16:9（13.333in × 7.5in）。
- 余白：左右0.6in、上0.5in。タイトル下に金の短い下線（幅2.2in・太さ3pt）。
- フッター：右下にページ番号、左下に「テニスプラザ尼崎 ご提案／アリガトサン」小さく。
- セクション扉：緑ベタ背景＋大きな白文字＋ゴールドのセクション番号。

## 4. 図解パターン（多用する）
1. **問題カード**：白カード＋左に番号バッジ（赤丸）＋「現象」＋「ひとことで」。GA4①〜⑥に使用。
2. **蛇口／バケツ／レジ図**：左=蛇口(SNS/検索・強い=緑)→中=バケツ(HP・穴=赤の破れ)→右=レジ(計測・無し=グレー×)。横フロー＋アイコン。
3. **採用ファネル図**：上から下へ台形/逆三角の段（LP到達650→応募50→面談22→…→承諾3）。各段に数字。
4. **チャネル配分図**：横棒 or ドーナツ（Instagram35/無料求人エンジン30/リファラル+地域25/チラシ10）。
5. **ロードマップ図**：左→右の4ステップ矢印（採用→近江手離れ→集客→西宮）。現フェーズを強調。
6. **3プランカード**：3列カード。Bに金枠＋「推奨」リボン、Cに緑枠＋「本命」リボン。価格を大きく。
7. **比較表**：◎○△−を色分け。ヘッダー緑。B列を薄黄でハイライト。
8. **価値比較バー**：人材紹介170-250万（赤・消える）vs 本提案（緑・残る資産）の対比バー。
9. **タイムライン**：契約後の週次（1週→8週）横帯。
- 図はベタ塗り＋角丸＋細い影。アイコンは絵文字 or 単純図形で代替（外部依存なし）。

## 5. トーン
- 専門用語は最小限。出たら必ず（やさしい補足）。比喩「レジ／蛇口・バケツ」を全体で一貫。
- 近江さん・山下社長が読んで分かる平易さ。数字は大きく1つだけ見せる。
- 押し売り感を出さない。「現状の事実→だから→選択肢」の順。
