## 3.【最重要】計測の実態 — GTM/GA4は“既に動いている”
- 公開フロントで **Google Tag Manager `GTM-PTKNCM87`** がライブ稼働（TCDテーマ設定 `script_code` 欄に直書きで全ページ出力）。
- そのGTM経由で **GA4 `G-GWGY9TGJ1Z` が実際に発火**（`googletagmanager.com/gtag/js?id=G-GWGY9TGJ1Z` をロード、`window.google_tag_manager['G-GWGY9TGJ1Z']` 存在）。
- 直書きの素のHTMLには GA4/gtag/Clarity/Pixel/Yahoo は無し ＝ **計測は全部 GTM-PTKNCM87 に集約**されている。
- ⇒ **context の「GA4未連携・計測ゼロ」は要修正**: GA4の**ページビュー計測は稼働中**。欠けているのは **CV計測6種（ネット予約/電話タップ/LINE相談/体験申込/アクセス確認/料金確認）のイベント設定**＝**GTMコンテナ内の設定作業**。「1月分が死んでいた」もGTM/GA4側の設定起因の可能性。
- **Plan A の新たな前提（最優先依存）**: **GTMコンテナ `GTM-PTKNCM87` と GA4プロパティ `G-GWGY9TGJ1Z` のGoogleアカウントアクセス**を取得すること。これがあればWPを触らずGTM上でCV計測・Clarity・流入計測を一元設定できる。所有者（山下コーチ／旧制作会社／GA代行者）を特定して権限付与を依頼する。
