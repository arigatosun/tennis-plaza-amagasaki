# テニスプラザ尼崎 採用ブランド伴走支援 — 社内提出サマリー(火曜提出)

## 結論
90日で「社員1＋バイト2」を採用完了し、近江(まやの)を現場固定シフトから外すことを取りに行く。これが本案件のNorth Star。採用→集客→西宮テニスクラブ再建の順で長期伴走。最初の勝ち筋は「計測ゼロ」「IG資産がHPに繋がっていない」という穴を塞ぐこと。

## 現状の実数(クリティカル3点)
- CV計測がゼロ・未設定 — 月1,650訪問あるが成果が一切測れていない(改善の前提が欠落)。
- SNS自然流入→HPが月25(全体の1.5%)のみ — フォロワー893・リール最大18.5万再生の資産が死んでいる。
- 有料SNS広告(Paid Social)が無駄打ち — 12か月で292・滞在22秒、出稿主も費用対効果も不明。

## KPI(North Star + 逆算)
- North Star: 90日で社員1+バイト2を採用完了→近江が現場固定シフトから外れる。
- 応募50件からの逆算(歩留まり【仮置き】・安全係数2.5): LP到達650→応募50→カジュアル22→最終9→内定5→承諾3。
- チャネル配分: Instagram 40% / 媒体(doda等) 30% / HP-SEO 20% / チラシ 10%。
- 最大の伸び代: IG経由LP到達 現状25/月→260/月(約10倍)。

## Phase0(計測基盤)が最優先である理由
測れないものは改善できない。現状CVゼロでは、IG・媒体・SEO・チラシのどれが応募を生んだか判別できず、予算配分も歩留まり補正も不可能になる。永吉フレームで言えば、蛇口(媒体)を開ける前にバケツ(受け皿)の穴を塞ぐのが先。計測を最初に固めることで、以降の全施策がデータドリブンで回り、KPIの逆算(LP到達650→承諾3)が実数で追えるようになる。逆に計測を後回しにすると、ブランドもLPも「効いたかどうか分からない」まま走ることになり、90日後に振り返れない。

## 90日の流れ(順次必須・短縮しない)
Phase0(計測基盤) → ブランド確定(Who-What-How) → 受け皿(求人票/LP/LINE) → 流入(IG/媒体/SEO/チラシの蛇口) → 充足(承諾3達成・近江手離れ)。各フェーズは前段の確定が前提のため並列化で短縮しない。

## 各人への依頼
- 吉川(技術=Phase0計測実装): CVキーイベント6種(体験予約完了/問い合わせ送信/電話タップtel:/入会フォーム到達/LINE登録クリック/資料DL)、Search Console連携、utm付与設計、404→301、KPIダッシュボード。最優先・他フェーズの前提。
- 中村(整理/媒体/採用管理): **無料媒体の構築**(engage一括配信/Google for Jobs/ハローワーク/ジモティー/リファラル ※人材紹介doda等は成功報酬30-35%=社員1人85〜123万円で除外)、採用管理シート構築、応募→カジュアル→内定の着地導線設計、KPI週次更新。詳細は `tennis_plaza_recruit_media_strategy.md`。
- 永吉(顧問マーケ=レビュー観点): Who(誰を採るか)-What(何を訴求するか)-How(どう届けるか)とブランドのレビュー。バケツ(受け皿)の穴が塞がっているか、蛇口を開ける順序が正しいかを監査。

## MTG(6/15 10時・山下/近江)で確定する数字(優先順)
1. 採用人数・期限・予算(KPIの土台)
2. 待遇条件(社員/バイトの給与・シフト)
3. SNS有料広告の出稿主・費用(無駄打ちの正体)
4. 現スタッフ数・過去の採用経路
5. 月謝単価・体験→入会率・退会率(集客フェーズの前提)
6. チラシ配布先の可否

## 工数/期限オーバー時の3択
- [A] 品質維持+納期延長(推奨) — 計測→ブランド→受け皿の順序を崩さない。
- [B] スコープ削減 — IG+媒体+LINEに集中(SEO/チラシを後送り)。
- [C] 近道許容(非推奨) — 計測を簡易化しブランド前に流入を開ける。犠牲=効果検証不能・予算配分が勘になる。
