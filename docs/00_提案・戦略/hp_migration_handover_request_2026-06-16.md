## 🔄 ベンダー回答（2026-06-22）で前提修正 ※詳細: `vendor_reply_2026-06-22.md`
- **①サーバー / ②ドメインのログインは渡せない**: 他顧客と**共用環境**のため。⇒「Xserver1か所集約・引き継ぎシンプル」の前提は崩れる（Xserverはベンダーの相乗りアカウント）。
- **ドメインは AuthCode（オースコード）移管のみ**: 必要時にベンダーが発行→移管先で手続き。**サーバー現物にはAuthCode相当の引き渡し手段なし**。
- **③HP管理画面は受領**: 実機確認の結果 **WordPress 確定**（`/login_93048` は `wp-login.php` をセキュリティプラグインで改名したもの・独自CMSではない）。⇒ WP標準のエクスポート/移行・タグ挿入が使える（③アカウントの**権限ロール確認が前提**）。
- **作業順序の注意**: サイト現物の確保（エクスポート等）→ その後ドメイン移管・DNS切替。逆だと管理画面URLが一時不通。
- **AuthCodeは今すぐ依頼しない**: Plan A計測先行で当面サーバー移行しないため。期限 2026/09/30 の手前（遅くとも9月上旬）に実移行直前で依頼。
- **資格情報（③のID/PW）はリポジトリに記載しない**: パスワード管理ツールへ。NDA未締結（T-01）のまま受領済み＝NDA先行で遡及カバー。

1. ★**エックスサーバー（Xserver）アカウント** … ログイン用メールアドレス＋パスワード、または会員ID。**これ1つでサーバー・DNS・WordPressの大元に届く（本命）**。
2. **ドメイン tennisplaza.jp の管理画面** … 多くはXserver内（エックスサーバードメイン）。別会社（お名前.com等）の可能性も残るので所在を確認。更新期限 2026/09/30 が近いので押さえたい。山下コーチ名義。
3. **WordPress 管理画面** … ログインURL・ユーザー名・パスワード（サーバーから辿れるが、もらえれば早い）。
4. （任意）現在のサーバー・ドメインの契約状況（プラン・支払者・更新時期）。
