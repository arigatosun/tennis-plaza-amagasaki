# 1. MTG 詳細総括（しゅうとと擦り合わせるためのファクトベース）

## 1.1 会の前提と中田の入り方

中田が冒頭で明確に打ち出したスタンス:

- アリガトサンは LP・Web 受託の会社
- **「曖昧に理解して進めて、お客さん怒られる」リスクを避けたいので、今日は提案ではなく深掘りヒアリングの場**
- デモも持参はしているが「この金額でやれます」ではなく、次回提案前の整理
- → これは正解。山下・近江ともに本音をかなり開けてくれた。次回もこのスタンス維持で OK。

## 1.2 当初の認識 vs 実情の決定的なズレ

| 項目 | 中田の事前認識 | 実際の状況 |
|---|---|---|
| 主課題 | 生徒を増やしたい | 生徒は**右肩上がりで潤沢**、**スタッフが足りていない** |
| ボトルネック | 集客導線 | 採用・育成・属人化・社長の手離れ |
| 提案方向 | 集客系 LP / Web | 採用 LP・人事制度・組織開発・脱属人化 |

**ここを今日 1 回目で発見できたのが最大の収穫**。事業者ヒアリング 1 回目で打ち手の方向を 180度回せるかどうかが分かれ目だった。

## 1.3 テニプラ尼崎のビジネス特性（事業理解）

- **業態**: 小規模インドアテニススクール × サービス業色を強めたカジュアル路線
- **差別化**:
  - 大手チェーンの「ゴリゴリのテニスコーチ」型ではなく、「楽しませる・寄り添う」型
  - 山下コーチが独立時に「固定費が高いから幅広く取らないと回らない」と意図的に営業色を強めた
  - これが「ベテランのテニスコーチを採ると合わない」「野心のある若手のほうが成果出る」構造を生んでいる
- **顧客層**: 30〜70代でバランス良く分散（3:3:3:1）、動機は**健康がメイン**
- **K-6（10年経った街・新興住宅地）×口コミ×小学校〜中学校への成長**で地に足ついた拡大基盤あり

## 1.4 入会率の異常値とその原因（=近江まやのの個人能力）

| 指標 | 数値 |
|---|---|
| 体験 → 入会の決定回数 | **1回**（=体験当日に決まる） |
| 入会率（近江参入前 2年連続） | 約 6割 |
| 入会率（近江参入後・直近） | **約 8割** |
| 7-8年での会員増 | 100人 |
| 直近 1年での会員増 | **50人**（=直近1年で過去7年と同等以上のペース） |

**この異常値はほぼ近江まやのの個人能力に依存している**。これがそのまま本ディールの最大の論点になる。

## 1.5 近江まやのの営業手法（属人ナレッジの解像度）

近江本人が自己分析として語った内容:

- 体験者が来たら、コートに行く前に**フランクな雑談**から入る
- ヒアリング項目は脳内チェックリストでさらっと聞く（紙のマニュアルは「読まれる用」で実態と乖離）
- 「断られへんことを全部考えていく」（クロージング前のリスク先回り）
- **「めっちゃ褒める」「自分のキャラ（タメ口・親近感）」を武器化**
- マニュアル通りに後輩がやると「ほんまのカウンセリングになってしまう」（=雑談感が出ず取れない）

**本人の見立て**: 「これは私のキャラやから、彼（後輩）がやったら怒られる。だからシステム化は無理」

**中田の見立て**: 「人それぞれだが、近江本人にしかできない8割を、AI / 動画 / ケース DB で6割まで再現できれば十分。最後の2割は近江本人が触媒で残す」 ← ここが提案のコアになる。

## 1.6 採用の論点（テニプラ ⇄ アリガトサンの議論の核心）

### 山下コーチの当初構想
- 健康志向の中年層向けに、テニスは下手でも営業上手な人材を採りたい
- ただ「テニスが好きな人」を採る文化が強かった

### 中田の介入提案（議論の流れを変えた）
- スポーツ業界はみんなまったりしている → ギラギラ層が枯渇している
- 「テニスが好き」は採用条件として弱い。むしろ**「業界を成長させたい/事業を作りたい」野心**で採るべき
- ペルソナ: **不動産・コンサル・金融出がりで、権限が欲しくて燻ぶっている層**
- 採用枠の名称を「営業」ではなく「**事業開発**」にする
- 山下コーチ完全同意

### 山下コーチが乗ってきたあとの言葉
> 「ギラギラ言いましょうよ」「すごいハングリー、いいことです」
> 「自分はもう全日本優勝するつもりもない、爆発するつもりもない。これからは人にギラつかせる仕事をする」

→ **既存事業の利益を一回吐き出して、人材投資に振り切る覚悟**を山下コーチが明言。これは次回提案の地盤として極めて重要。

## 1.7 給与・評価制度の現状と論点

### 現状
- 週休2日、残業ゼロ、自宅作業なし、超ホワイト
- 基本給がそこそこ高くて生活できる設計
- インセンティブは「あったら増える / 無くても減らない」のオプション
- 評価制度は「明確にはなくて感覚的」

### 山下コーチの本音
- 既存スタッフを基本給15万＋インセンティブ型に切り替えるのは無理（みんな辞める / 既得権益破壊）
- できる人だけにバックする仕組みは「平等ではなく公平」だが、マイナス評価は怖くてつけられない
- 人手不足の希少価値で給料が決まる業界（=人材市場側の構造）

### 議論で出た解決方向
- **新規ギラギラ枠（事業開発）は、既存とは別パッケージ・別カルチャー**にする
- 部門で給与・評価を分けることへの抵抗は山下コーチ側に無し
- 山下コーチ: 「スポット人事評価制度を作ってくれる人に発注して、うち独自の人事評価を作って回す案も持っていた」 ← **これは直接アリガトサンに振れる玉**

## 1.8 近江まやの本人の野心とアンビバレンス

### 野心側
- 「バリバリ稼ぎたい」「男に養われたくない」「自分のキャリアが欲しい」
- 「お金で困ったことがないように、娘にもしてあげたい」
- 山下コーチが言うように「ライバル立てて運賞」のほうがやりやすいタイプ

### 仲間志向側（本心）
- 「本間は私、普通にプラッポやから、みんなで仲良く仕事してるから、嫌いじゃない」
- 「みんなで仲良く、それぞれの能力を出し合って、能力が足りないものは考える人がやってというのをしたいだけ」
- 「対立してしまったから、ドーンとなってしまっただけ」 ← **過去に社内対立があった示唆**

### 結論
- バリバリ稼ぎたいけど、本心は協業型。**「組まされる相手」が重要**
- 中田 vs 近江タイプではなく、**「近江がやりたいことに伴奏してくれる人」が刺さる**
- これは次回提案で「アリガトサンとして近江とどう組むか」の言語化に直結

## 1.9 西宮テニスクラブ（新規事業）の構想

- 山下コーチ構想: 0人を 50人に伸ばす新規拠点
- **近江まやのを事業責任者として送り出したい**山下コーチの意思は明確
- ただし、近江は今の尼崎オペから手が離せない（属人化）
- スクールバスの全面改装は事情で難しい / 軽量キャンペーンは予算 OK
- 中田: 「[近江]と組んで西宮を 0→50 やりたい」と踏み込んでいる
- これが「単発受託」ではなく**長期パートナーシップ**になる重大なフック

## 1.10 山下コーチ自身の課題感（経営者個人の話）

- 「現場のテニスコーチからガッツリ離れたい」けど、回らないので戻ってしまう
- 子供がまだ小さく、家族との時間も大事
- 「自分が行ったら100%取れる」と分かるからつい口を出してしまう
- 「すぐ突き放さないとあかんと分かっているが、できない」
- → **山下コーチも近江と同じく属人化に縛られている。経営者の手離れも提案範囲**

## 1.11 後半・近江の本音吐露（part2 中盤）

- 「給料もらってる上で寄り添うのは前提。でもあっちは私らの立場を考えてはくれない」
- 「こっちの優しさを利用されたことが多すぎて、ドライになってしまった」
- 「天狗になってるつもりはない、能力もセンスもあると思った部分もある、めっちゃ勉強した部分もある」
- 「努力したら誰でもなれる、テニスしかしてへんかった私、成績出なかった私でも今こうなってる」
- → 防衛的な感情が前面に出る瞬間あり。次回提案では「近江を否定しない」「8割の仕組みと2割の近江触媒」というフレーミングを徹底すべき

## 1.12 中田が示した「脱属人化の自社実例」

これが議論の決定打になった一節:

> 「俺らの会社もワンマン状態だった。中村しか営業できない、俺しかエンジニアできない。それを仕組みに落として、めっちゃ頑張ってこの 1-2年で。今、未経験で入った人が**1週間のブートキャンプで案件 1人で回せる**ようになって、代表のプロジェクトを引き継いで最後までリリースまで持っていってる」

近江の反応: 「**できるのは分かった**。やったことがないから、ほんまに（分からない）」

→ **アリガトサン自身の脱属人化事例は、テニプラへの最強の信頼担保。次回提案でもっと厚く語るべき**

## 1.13 クロージング（part2 末尾）

- 中田: 「ヒアリングめっちゃさせてもらった。中村も次の商談で 13時から出るから一旦持ち帰る」
- 山下コーチ: 持ち帰り OK の流れ
- 中田: **「最後にほんまスラーっとだけ俺が作ったからさ、見てほしいね採用用のLPを」** ← 当日デモは見せられた模様

# 2. エグゼクティブサマリー（中村しゅうと向け・次回提案方針）

## 2.1 結論（最初に1行で）

**「Web 制作会社からの LP 提案」ではなく、「採用 × 脱属人化 × 西宮拡張」の組織開発パートナーとしてポジションを取りに行く。** 採用 LP は最初の入口にすぎず、本筋は近江まやの形式知化 + 事業開発職採用 + 西宮事業立ち上げの長期伴走。

## 2.2 クライアントの本質課題（再掲）

1. **属人化**: 近江まやのに営業がほぼ全依存（入会率 8割 / 直近1年で 50人増）
2. **採用**: 既存業界人材では伸びない。**業界外ギラギラ層**を「事業開発職」として獲りに行く必要
3. **手離れ**: 山下コーチも近江も現場から離れたいが離れられない
4. **新規事業**: 西宮テニスクラブ 0→50 を 1 年で。近江を事業責任者にしたい
5. **既存組織**: ホワイト・基本給型の現場層は守る必要あり（破壊不可）

## 2.3 提案テーマ4本（中村と優先順位を決める）

### A. 採用 LP 本実装＋採用運用パッケージ【入口/即着手】
- 当日デモを見せた採用 LP の本実装
- ペルソナを「テニスコーチ」から**「事業開発職を任されたい不動産/コンサル/金融出身者」**に再定義
- 訴求軸: 権限 / 予算 / 山下コーチの既存事業実績 / 近江という共闘相手 / アリガトサン伴走
- 媒体: Wantedly / Green / 業界外スカウト DM 設計
- 応募→面接→トライアル設計まで一気通貫

### B. 近江まやの営業ナレッジの形式知化【中核/差別化】
- 体験当日のヒアリング〜クロージングのフルプロセス言語化
- 動画ロープレ＋テキスト＋**AI ロープレ（近江の声・話法を学習）**
- ケーススタディ DB（年齢層 × 動機 × 反応パターン）
- 新人向け社内アプリ（イエスノー直感クイズ / 月次運用 / 100点化）
- **アリガトサンの自社ブートキャンプ式メソッドを横展開**（これが信頼の根拠）

### C. 評価・給与制度の二層化設計【B のあと/制度系】
- 既存「ホワイト・基本給ベース」は維持
- 新規「事業開発・ギラギラ・フルインセンティブ」枠を別パッケージで新設
- 役職定義 / キャリアステップ図 / スポット人事評価制度
- 山下コーチが「外注も検討していた」と明言した玉

### D. 西宮テニスクラブ立ち上げ伴走【後期/長期収益化】
- 0→50人 / 1年 のロードマップ
- 軽量キャンペーン中心（改装予算 NG 前提）
- 近江を事業責任者として送り出す前提のオペレーション再構築
- アリガトサンが Web / LP / 集客運用で常駐伴走

## 2.4 推奨フェーズ分け

| Phase | 期間 | やること | 課金モデル |
|---|---|---|---|
| 0. 次回提案 | 〜2週間 | A の精緻提案 + B のミニ PoC（近江ヒアリング動画 1本 + AI ロープレ MVP） | 提案無料 / フック作り |
| 1. クイックウィン | 1〜2ヶ月 | A 本実装 + B 第1弾（ケース DB 着手） | プロジェクト |
| 2. 仕組み化深化 | 3〜6ヶ月 | B 本格化 + C 制度設計 | 月額伴走 |
| 3. 拡張 | 6ヶ月〜 | D 西宮立ち上げ | 月額伴走＋成果報酬ハイブリッド |

## 2.5 中村と詰めるべき論点（次回提案前にやる打ち合わせ）

優先度高い順:

1. **B（ナレッジ形式知化）の MVP 範囲** … 次回提案で見せる「近江の脱属人化はこういう絵になります」のサンプルをどこまで作り込むか。AI ロープレを実演デモで持っていくか、絵で示すか。
2. **A（採用 LP）の修正方針** … 当日デモを見た山下・近江のフィードバック反映。事業開発職への振り切り度合い。
3. **見積もり・体制の合意** … プロジェクト型 / 月額伴走 / ハイブリッドのどれを軸にするか。フェーズ 1 で月幾らを提示するか。
4. **西宮テニスクラブの位置付け** … 次回提案で言及するか、Phase 1 完了後に出すか。早すぎると引かれる可能性。
5. **アリガトサン自社事例の見せ方** … 「未経験者が1週間で案件回せるブートキャンプ」を提案資料の中でどう資料化するか。これは強力な信頼担保。
6. **近江まやのへの伝え方** … 「あなたを否定しない、8割の仕組みと2割の近江触媒」のフレーミング徹底。コンサル臭・押し付け臭を徹底排除。
7. **山下コーチへの伝え方** … 「自分の手離れ」を解決テーマに含めるかどうか。本人は薄々分かっている。

## 2.6 提案時に避けるべきこと（地雷リスト）

- ❌ **マニュアル化を 0/100 で語る** … 近江は「マニュアル化は無理」と何度も言っている。「8割の仕組み化、残り2割は近江本人」のフレーミング厳守
- ❌ **既存スタッフのインセンティブ化** … 山下コーチが明確に NG。新規枠の二層化が正解
- ❌ **「テニスが好きな人を採りましょう」** … この方向は議論で完全に否定された
- ❌ **山下コーチに「もっと現場から離れて」と直接言う** … 本人も悩んでいる。共感ベースで
- ❌ **コンサルっぽい上から目線** … 「コンサル嫌い」と明言あり。「一緒にやる」「俺らも同じ状態だった」ベース

## 2.7 次回提案で勝つための「核」（中田の打ち手仮説）

> **「近江まやのを否定せず、8割を仕組み化して 2割を彼女の触媒として残す。アリガトサンが自社で 1-2 年かけて達成した脱属人化のメソッドを、テニプラ尼崎にそのまま移植する。最初の半年は採用 LP と AI ロープレ、その先で西宮テニスクラブ立ち上げまで伴走する。」**

これを次回 1 枚絵で見せられるか、中村と詰めたい。
